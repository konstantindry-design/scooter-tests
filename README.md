# scooter-tests

Автотесты для веб-приложения «Самокат» (Учебный проект Яндекс Практикума).

## Стек технологий
- Java 11+
- Selenium WebDriver 4.15.0
- JUnit 4
- AssertJ
- Maven

## Требования
- Установленный JDK 11 или выше.
- Браузер Google Chrome (последней версии).
- Доступ к тестовому стенду: `https://qa-scooter.praktikum-services.ru/`

## Запуск тестов

### Локально
1. Убедитесь, что переменные окружения `JAVA_HOME` настроены корректно.
2. В терминале в корне проекта выполните:
   ```bash
   mvn test
